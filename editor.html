3. Добавить персонажа

Фото обычно подбирается автоматически по ID — файл images/<id>.jpg. Это поле нужно только для персонажей без ID или для замены картинки вручную.

4. Массовый импорт (вставить текстом)

Вставьте один или несколько персонажей в привычном формате (каждая строка "Поле: значение", персонажи подряд) — так же, как вы присылаете их в чат. Значения активности/БУ/должности/пола будут автоматически сопоставлены со списком допустимых — что не распознано, получит «-».

5. Экспорт

Заменит файл js/data.js в вашем проекте — просто перезапишите его этим файлом и загрузите на GitHub.
