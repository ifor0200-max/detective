# Поиск персонажей

Статический сайт для поиска персонажей по параметрам: Имя, Возраст, Статус,
Активность, БУ, Семья, Должность, Пол, Фото. Фильтрация происходит прямо
в браузере, без сервера и баз данных — подходит для размещения на
GitHub Pages.

## Структура проекта

```
character-finder/
├── index.html          — страница с формой фильтра и списком результатов
├── css/style.css        — оформление
├── js/data.js            — БАЗА ПЕРСОНАЖЕЙ (редактируете именно этот файл)
├── js/app.js              — логика фильтрации, ничего менять не нужно
├── images/                — фотографии персонажей
└── tools/editor.html      — редактор базы (удобная форма вместо ручной правки data.js)
```

## Как добавить нового персонажа

Два способа — выберите удобный.

**Способ 1: редактор `tools/editor.html`.** Откройте этот файл прямо в
браузере (двойной клик, интернет не нужен). Можно:

- загрузить текущий `data.js` и редактировать список в таблице;
- добавлять персонажей по одному через форму — все ограниченные поля
  (Активность, БУ, Должность, Пол, Семья) там уже выпадающие списки,
  ошибиться в значении не получится;
- вставить в поле «Массовый импорт» текст в привычном формате (как вы
  присылаете в чат: `Имя: ...`, `Возраст: ...` и т.д., несколько
  персонажей подряд) и нажать «Разобрать и добавить» — редактор сам
  распознает поля, сопоставит значения со списком допустимых и покажет,
  что не удалось распознать;
- нажать «Скачать data.js» — получите готовый файл, останется положить
  его в папку `js/` вместо старого и загрузить на GitHub.

**Способ 2: вручную.** Откройте `js/data.js`, скопируйте один из объектов
в массиве `characters`, вставьте копию перед закрывающей строкой `];` и
заполните поля:

```js
{
  id: "205834",
  name: "Имя персонажа",
  age: 25,
  status: "не перерожден",
  activity: "Частичка Игровой",
  power: "Идеальная",
  family: "Крэндалл",
  position: "Питомец семьи Крэндалл",
  gender: "Кот",
  photo: ""
}
```

Сохраните файл и загрузите изменения на GitHub (commit + push).

### Допустимые значения полей

Для полей ниже сайт (и редактор) ожидают значения СТРОГО из этих
списков. Если значение персонажа неизвестно или не подходит ни под одно
из них — ставьте `"-"` (дефис), это специальное значение «не указано».

- **family (Семья):** Аллен, Крэндалл, Вурхиз
- **activity (Активность):** Сверхидеальная, Идеальная, Хранитель Игровой,
  Частичка Игровой, Император Игровой, Ходячий миф, Легенда сайта,
  Любимый кот, Замечательнейшая, Замечательная, Улучшающаяся,
  Положительная, Переходная, Отрицательная, Ухудшающаяся, Ужасная,
  Ужаснейшая, Забытый кот, Забывший про игру, Покинувший игру,
  Подлежащий удалению, Пустое место
- **power (БУ):** Блоха, Котёночек, Задира, Гроза детской, Страх
  барсуков, Победитель псов, Защитник племени, Великий воин, Достоин
  Львиного племени, Идеальная
- **position (Должность):** Старший семьи Крэндалл, Старший семьи Аллен,
  Старший семьи Вурхиз, Питомец семьи Крэндалл, Питомец семьи Аллен,
  Питомец семьи Вурхиз, Котенок
- **gender (Пол):** Кот, Кошка

Поле **status (Статус)** свободное — строгих ограничений на него пока
нет, выпадающий список на сайте собирается из того, что реально
встречается в `data.js`.

## Как привязать фото к персонажу

Фото привязывается **по id персонажа** (айди игрока на catwar.net) —
редактировать `data.js` для этого не нужно.

1. Заполните поле `id` у персонажа — это его игровой ID.
2. Сохраните файл с фото в папку `images/` под именем `<id>.jpg`
   (подойдёт и `.jpeg`, `.png`, `.webp` — сайт сам перебирает расширения
   по очереди, указывать его отдельно не нужно).

   Пример: у персонажа `id: "205834"` фото должно называться
   `images/205834.jpg`.

3. Обновление `data.js` не требуется — просто добавьте файл в `images/`
   и загрузите его на GitHub. Пока файла нет, вместо фото показывается
   плашка «Нет фото».

Поле `photo` в `data.js` нужно только для персонажей **без id** —
впишите туда путь к файлу (например, `"images/moy-fayl.png"`) или
прямую ссылку на изображение. Ручное значение `photo` всегда имеет
приоритет над автоматическим подбором по id.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите туда все файлы этого
   проекта (сохраняя структуру папок).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a
   branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через минуту-две сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Локальная проверка перед публикацией

Достаточно открыть `index.html` в браузере. Если фото не отображаются из-за
ограничений браузера на открытие файлов напрямую, запустите локальный
сервер из папки проекта:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000` в браузере.
